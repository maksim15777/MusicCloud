==================================================================
        ИНСТРУКЦИЯ ПО ЗАПУСКУ СЕРВЕРА MUSICCLOUD (WINDOWS)
==================================================================

Этот скрипт является локальным сервером-прослойкой, который держит
настоящее соединение Telegram MTProto с вашим аккаунтом.

ШАГ 1. УСТАНОВКА PYTHON (если еще не установлен)
- Скачайте Python 3.10+ с https://www.python.org/
- ВАЖНО: При установке обязательно поставьте галочку "Add Python to PATH"!

ШАГ 2. ЗАПУСК В 1 КЛИК
- Просто дважды кликните по файлу: run_server.bat
- Скрипт сам установит нужные библиотеки (FastAPI, Telethon, Uvicorn)
  и запустит сервер на порту 8000.

ШАГ 3. ПОДКЛЮЧЕНИЕ С IPHONE
1. Узнайте локальный IP вашего компьютера:
   - Откройте PowerShell/CMD и введите: ipconfig
   - Найдите строку "IPv4-адрес" (например: 192.168.1.45)
2. В приложении MusicCloud на iPhone X:
   - Внизу экрана входа нажмите на плашку "Сервер: ..."
   - Введите: http://192.168.1.45:8000 (вместо 192.168.1.45 укажите ваш IP)
   - Нажмите "Сохранить".
3. Введите номер телефона, получите настоящий код в Telegram и наслаждайтесь музыкой!

ВАЖНО:
- Компьютер и iPhone должны быть подключены к одному Wi-Fi роутеру.
- Либо вы можете запустить ngrok: "ngrok http 8000" и вставить публичную ссылку https://... в приложение.
