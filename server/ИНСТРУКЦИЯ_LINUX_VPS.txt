==================================================================
      ИНСТРУКЦИЯ ПО ЗАПУСКУ СЕРВЕРА НА LINUX VPS (UBUNTU/DEBIAN)
==================================================================

Сервер на Linux VPS позволяет приложению MusicCloud работать отовсюду
через мобильный интернет (LTE/5G) или любой Wi-Fi 24/7!

ШАГ 1. ПОДКЛЮЧИТЕСЬ К ВАШЕМУ VPS ПО SSH
ssh root@IP_ВАШЕГО_СЕРВЕРА

ШАГ 2. ВЫПОЛНИТЕ ВСЕГО 3 КОМАНДЫ ДЛЯ УСТАНОВКИ И ЗАПУСКА:

1) Клонируем проект:
git clone https://github.com/maksim15777/MusicCloud.git

2) Переходим в папку сервера:
cd MusicCloud/server

3) Запускаем установочный скрипт:
bash start.sh

Сервер запустится на порту 8000!

------------------------------------------------------------------
КАК НАСТРОИТЬ 24/7 РАБОТУ В ФОНЕ (ЧЕРЕЗ SYSTEMD):
------------------------------------------------------------------
Чтобы сервер не выключался после закрытия консоли:

sudo cp musiccloud.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable musiccloud
sudo systemctl start musiccloud

Проверить статус:
sudo systemctl status musiccloud

------------------------------------------------------------------
ПОДКЛЮЧЕНИЕ С IPHONE:
------------------------------------------------------------------
1. В приложении MusicCloud на iPhone X:
   - Внизу экрана нажмите "Сервер: ..."
   - Введите: http://IP_ВАШЕГО_VPS:8000
   - Нажмите "Сохранить".
2. Введите номер телефона, получите код в Telegram и слушайте музыку!
